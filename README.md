# Sistema de Chamados de TI

Sistema web desenvolvido para registrar, consultar e gerenciar solicitações de suporte técnico.

Projeto desenvolvido como parte do meu portfólio na área de Análise e Desenvolvimento de Sistemas.

## Demonstração

Acesse o sistema:
https://jonh-alisson.github.io/sistema-chamados-ti/chamados.html

## Funcionalidades

- Cadastro de chamados de suporte técnico.
- Geração automática de protocolo.
- Classificação por categoria e prioridade.
- Consulta e pesquisa por protocolo.
- Filtros por status e prioridade.
- Atualização do status dos chamados.
- Exclusão de chamados.
- Painel com indicadores de atendimento.
- Geração de relatórios em PDF.
- Exportação de dados para Excel (CSV).

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage para armazenamento dos dados no navegador.

## Objetivo do projeto

Praticar e demonstrar conhecimentos em desenvolvimento web, manipulação de dados, lógica de programação e criação de funcionalidades para gerenciamento de solicitações de suporte técnico.
